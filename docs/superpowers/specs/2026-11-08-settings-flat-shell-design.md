# Settings 平铺式外壳与导航重构

日期：2026-11-08
设计稿：`docs/designs/settings-shell-redesign.html`

## 目标

把 Settings 从「桌面式浮动侧栏 + 半屏留白 + 悬浮工具栏」改成像设计稿那样的平铺布局：

- 侧栏常驻、按组排列，内容区从窗口顶部开始。
- 页头固定，标题与页面操作同一行；只滚动内容。
- 列表+详情页面在宽屏使用主从两列，窄屏推入详情并返回。
- 窄窗口时侧栏退化为图标栏，再窄退化为抽屉。

## 非目标（硬约束）

- **不修改任何设置项的功能、字段、默认值和读写逻辑。** 本次只改外壳与页面容器。
- 不实现「此设备」页（设计稿保留，另行安排）。
- 不合并或删除导航页面。
- 不修改其他应用使用的外壳（`DenialApplicationFrame` 保持原行为）。
- 不修改 deniald、设置文档结构、l10n 文案（除少量新增的导航分组标题/无障碍标签）。

## 布局规范

### 侧栏

- 宽 272 逻辑像素，背景 `--sidebar`，右侧 1px 分隔线，与内容同高、无圆角、无悬浮。
- 顶部品牌行：设置图标 + 「设置」，内边距 22/12/18。
- 分组顺序与标签：
  - 个性化：你、外观、语言
  - 输入：键盘、鼠标和触控板、快捷键
  - 桌面：应用环境、动画、桌面布局、浮层、锁屏
  - 系统：权限、音频、显示器与视频、网络、蓝牙、电源、开发者
- 分组标签 11px、字重 600、字距 0.08em、`--faint`，上下间距 6/14。
- 条目高 40、圆角 11、图标 17、文字 13.5；选中项使用胶囊底色 + 文字加粗 + 主色图标。
- 底部固定「关于」，上方一条分隔线，不随分组列表滚动。
- 分组列表在高度不足时独立滚动，底部项始终可见。

### 内容区

- 顶部页头：左侧标题（27/700）与描述（13/次要色），右侧为页面操作胶囊按钮（高 36，圆角 999，1px 边框）。
- 页头下边 1px 分隔线；页头固定，内容区滚动。
- 内容列最大宽度 1180，水平居中；页头与卡片列使用同一容器对齐。
- 内容区左右内边距 40，顶部 24，底部 28。
- 卡片：白底、1px `--line` 边框、圆角 20、内边距 22/26；卡片间距 16。
- 卡片标题 14.5/700，前置 17px 主色图标；描述 12/次要色。
- 页头右侧为窗口「⋯」菜单预留至少 64px 安全间距，避免按钮重叠。

### 状态与反馈

- 同步中/同步失败覆盖层保持现有实现与行为。
- 页面错误提示从原来的悬浮 footer 改为内容列底部的提示卡，位置随内容滚动。
- 保存状态徽标保持现有控件与语义。

## 响应式

以 `MediaQuery.sizeOf(context).width`（逻辑像素，已含 1.3 应用缩放）为准：

| 宽度 | 导航形态 |
| --- | --- |
| ≥ 1200 | 完整侧栏 272 |
| 760–1199 | 图标栏 72：只显示图标，隐藏分组标签与文字，保留分组分隔线；长按显示名称提示 |
| < 760 | 抽屉：页头左侧显示菜单按钮，侧栏以 280 宽滑入并加遮罩，点遮罩关闭 |

断点使用应用内逻辑像素：独立 Settings 外壳按 1.3 倍缩放布局，因此横屏平板约 1313、竖屏约 820。横屏得到完整侧栏，竖屏保留图标栏而不是直接退化成抽屉；只有真正的窄窗口才使用抽屉。

- 三种形态共用同一分组顺序与选中状态。
- 图标栏和抽屉中选中项仍使用胶囊底色。
- 断点切换不重建页面状态（滚动位置与本地编辑状态保留）。

## 页面契约

`SettingsPageLayout` 保持现有入参（icon、eyebrow、title、children、onReset、commands、footer、cardSpacing），内部改为：

- 渲染页头（标题 = eyebrow，描述 = title，右侧 = commands + 重置）到固定页头区。
- children 渲染为内容列中的卡片流。
- 新增可选 `leading`（窄屏返回按钮）与 `pinnedHeader`（默认 true）。
- 页面不再通过 `SettingsChromeController` 发布 toolbar；`SettingsPageChrome` 的 toolbar 槽移除，footer 语义改为页底提示区。

自定义外壳的四个页面（关于、快捷键、你、指纹）迁移到 `SettingsPageLayout` 或新的 `SettingsSplitLayout`，只改容器，不改内部控件。

## 主从页面

适用于应用环境、快捷键、权限（以及指纹页的设备列表，如结构相同）：

- 宽屏（≥ 900）：
  - 同一页头下，左侧列表卡固定 320 宽、自身滚动；右侧详情区独立滚动。
  - 两列间距 16；页面 body 本身不滚动，避免「页面滚动里套列表滚动」。
- 窄屏（< 900）：
  - 只显示列表；点条目推入详情，页头左侧出现返回按钮。
  - 返回时恢复列表滚动位置与选中项。
- 详情为空时右侧显示空状态（沿用现有文案）。

## 实现方案

1. SDK 新增 `DenialFlatApplicationFrame`（`packages/denial_flutter_sdk/lib/src/widgets/application_material.dart`）：
   - Row [navigation(272/72) | Expanded(content)]；可选 drawer 模式。
   - 内容区不提供 reveal 留白，不绘制 sheet。
   - 旧 `DenialApplicationFrame` 原样保留，其他应用不受影响。
2. `SettingsNavigation` 重写为分组列表，新增 rail 与 drawer 两种渲染；19 个目的地数据来自现有 `SettingsPageId`。
3. `SettingsPageLayout` 重写为「固定页头 + 滚动内容列」，新增 `SettingsSplitLayout` 供主从页面使用。
4. `settings_application.dart` 改用 `DenialFlatApplicationFrame`，按宽度选择 sidebar/rail/drawer；移除 toolbar 发布逻辑。
5. 逐页迁移容器：删除各页自建的 `DenialContentPane`/`SettingsPageChrome` 用法，不改控件与回调。

## 验证

- `flutter analyze`（插件 + SDK）无新增问题。
- 平板上逐页截图核对：横屏、竖屏、窄窗（拖动窗口到 <900）三种形态。
- 回归检查：18 个页面的原有操作（开关、滑块、选择器、重置、扫描、编辑）均可正常使用，且读写结果与改造前一致。
- 检查选中态、滚动位置、抽屉关闭、返回逻辑、窗口「⋯」菜单不重叠。

## 风险

- 页面内部存在基于宽度的手工 inset 计算，迁移后需要统一到内容容器，可能出现双重内边距。
- 1.3 应用缩放影响逻辑宽度，断点必须用逻辑像素判断，避免误判。
- 主从页面改为双列独立滚动后，平板上的滚动手势需要实测，防止与下拉栏手势冲突。
