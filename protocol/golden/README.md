# Wire golden fixtures

- `dart_input_*.denw` are generated by Dart and verified by Denial's native
  wire-protocol regression test.
- `native_windows_*.denw` are native-to-Dart compatibility snapshots decoded
  by the Flutter tests and benchmarks.
- `empty`, `one`, `eight`, and `many` represent 0, 1, 8, and 32 windows.

Fixtures intentionally cover Unicode strings, unsigned IDs larger than 32
bits, negative coordinates, fractional geometry, flags, and ordering.

Regenerate Dart fixtures from `dart_shell`:

```sh
DART="${XDG_CACHE_HOME:-$HOME/.cache}/denial/pc-dependencies/\
flutter-elinux/flutter/bin/cache/dart-sdk/bin/dart"
HOME=/tmp "$DART" \
  --packages=.dart_tool/package_config.json tool/generate_wire_goldens.dart
```

The native fixtures intentionally remain stable across compositor
implementations. When the Rust encoder changes intentionally, regenerate them
from its equivalent fixture data and review the decoded Dart model changes.
Normal builds never regenerate fixtures.
